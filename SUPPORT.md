# Suporte do Faturador

Se você encontrou um problema, tem uma dúvida ou precisa de suporte com o Faturador, verifique as opções abaixo:

- **Documentação:** Leia os guias na pasta `docs/` e os arquivos de apoio na pasta `arquivos/`.
- **Issues:** Abra uma issue no repositório do GitHub em [Rodpais/faturador/issues](https://github.com/Rodpais/faturador/issues).
- **Questões de Segurança:** Por favor, não abra issues públicas para falhas de segurança. Veja [SECURITY.md](SECURITY.md).
