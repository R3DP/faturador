# Contribuindo com o Faturador

Obrigado pelo interesse em contribuir com o Faturador! 

1. Faça um fork do repositório (`https://github.com/Rodpais/faturador`).
2. Crie um branch para a sua funcionalidade ou correção (`git checkout -b feature/sua-feature`).
3. Envie suas alterações com commits claros.
4. Abra um Pull Request para o branch principal ou `pt-br`.
